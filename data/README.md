# Data

Data nejsou součástí repozitáře (licence Kaggle).

1. Stáhni dataset **Should This Loan be Approved or Denied?** z Kaggle:
   https://www.kaggle.com/datasets/mirbektoktogaraev/should-this-loan-be-approved-or-denied
2. Ze ZIPu ulož `SBAnational.csv` do této složky: `data/SBAnational.csv`.

Kontrola: soubor má 899 164 řádků a 27 sloupců (~179 MB).

Zdroj: Li, M., Mickel, A., Taylor, S. (2018). "Should This Loan be Approved or Denied?":
A Large Dataset with Class Assignment Guidelines. *Journal of Statistics Education*, 26(1), 55–66.
